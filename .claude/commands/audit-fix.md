# Fix Dependencies

Виконай аудит та виправлення залежностей:

1. Запусти `npm audit` для перевірки вразливостей
2. Запусти `npm audit fix` для автоматичного виправлення
3. Якщо є критичні вразливості, які не виправились — запропонуй рішення
4. Перевір чи проект все ще працює після оновлень (`npm run build`)

Надай звіт:
- Скільки вразливостей було знайдено
- Скільки виправлено автоматично
- Які залишились і що з ними робити
